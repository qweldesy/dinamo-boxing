# Динамо — бойцовский клуб (макет лендинга)

Статичный макет сайта бойцовского клуба «Динамо» (Казань, ул. Горького, 10А),
сделанный по референсу тёмного «неонового» фитнес-лендинга.

## Как открыть

Вариант 1 — просто открыть файл в браузере:

- двойной клик по `index.html`

Вариант 2 — через локальный сервер (если установлен Python):

```
python -m http.server 8123 --directory <путь к папке dinamo-boxing>
```

и открыть http://127.0.0.1:8123/

## Состав

- `index.html` — разметка всех секций
- `css/style.css` — стили
- `js/main.js` — меню, reveal-анимации, счётчики, параллакс
- `images/` — реальные фото клуба (взяты с его страницы на Яндекс Картах:
  зал, акции, тренеры, аватарки авторов отзывов, логотип)
